# Acompanha

Repositório do projeto **Acompanha — Sistema de Acompanhamento Pedagógico Individualizado**, desenvolvido para a escolinha Divertindo a Mente na disciplina Trabalho Interdisciplinar: Aplicações para Processos de Negócio (PUC Minas Contagem).

> Sistema de Acompanhamento Pedagógico Individualizado para a Divertindo a Mente (Contagem/MG). Disciplina TIAPN, PUC Minas Contagem. Versão 2, revisada após a avaliação da Sprint 1 (atualizada em 25/09/2026).

## Estrutura do repositório

```
Acompanha/
├── README.md        este índice
├── docs/            definição do projeto, um documento por assunto
└── relatorios/      relatórios oficiais em Word (.docx)
```
