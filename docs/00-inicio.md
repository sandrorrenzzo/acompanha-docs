# 00. Início

Sistema web de acompanhamento pedagógico individualizado para a Divertindo a Mente, escolinha de reforço escolar em Contagem/MG. Passa a registrar aulas, tarefas e notas, que hoje não ficam anotadas em lugar nenhum, e dá aos responsáveis uma visão simples do progresso dos próprios filhos.

Projeto da disciplina Trabalho Interdisciplinar: Aplicações para Processos de Negócio (PUC Minas Contagem).
