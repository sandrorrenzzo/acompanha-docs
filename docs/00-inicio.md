# 00 — Início

Sistema web de acompanhamento pedagógico individualizado para a Divertindo a Mente, escolinha de reforço escolar em Contagem/MG. Substitui as planilhas usadas hoje pelas professoras no registro de aulas, tarefas e notas, e dá aos responsáveis uma visão simples do progresso dos próprios filhos.

Projeto da disciplina Trabalho Interdisciplinar: Aplicações para Processos de Negócio (PUC Minas Contagem).
