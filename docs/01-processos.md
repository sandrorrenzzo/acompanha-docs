# 01 — Processos de negócio

| Processo | Quem executa | Observação |
|---|---|---|
| Cadastro do aluno e coleta do consentimento | Professora + responsável | Aluno só fica ativo com consentimento registrado (RN08). |
| Cadastro e vinculação de responsáveis | Professora | Um aluno pode ter vários responsáveis; um responsável, vários alunos. |
| Registro de aula e presença | Professora | Base para frequência e continuidade entre professoras. |
| Gestão de tarefas de casa (criar, acompanhar, conferir) | Professora (responsável pode avisar) | Status alterado só pela professora (RN06). |
| Registro de avaliações | Professora | Nota de 0 a 10 (RN01). |
| Identificação e acompanhamento de reforço | Sistema + professora | Regra automática (RN04) e marcação manual. |
| Consulta do progresso | Responsável | Somente leitura e somente dos próprios filhos (RN07). |
| Encerramento de matrícula e eliminação de dados | Professora + sistema | Bloqueio imediato e eliminação no prazo (RN09, RN10). |
