# 04 — Objetivo

> Projeto Acompanha (TIAPN, PUC Minas Contagem). O que o projeto quer alcançar. Índice geral: [README](../README.md).

Desenvolver o Acompanha para automatizar o registro e o acompanhamento individualizado dos alunos (aulas, tarefas, desempenho por matéria), substituindo as planilhas e oferecendo aos responsáveis uma visão simplificada e segura do progresso dos próprios filhos, com ganho medido contra a linha de base.
